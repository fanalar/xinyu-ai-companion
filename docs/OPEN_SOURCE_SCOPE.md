# Release scope

This public tree starts with a new history from reviewed source. Original .git history, runtime databases, credentials, key stores, recordings, media, logs, local business documents, built installers/APKs and machine-specific test scripts are excluded.

Project-owned code is published under MIT with a project-level contributor attribution; individual names and contact details from local templates are not carried into public metadata. Third-party notices and licenses remain separately attributed. Original local files are unchanged.

The project remains a local prototype. Browser/API models use credentials supplied by the person running the application. No production hotel infrastructure or account/payment backend is provided.
